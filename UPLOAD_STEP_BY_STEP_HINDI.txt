LOANPAYBIMA - GITHUB DESKTOP UPLOAD

1) Is ZIP ko Extract All karo.
2) GitHub Desktop kholo.
3) Current repository: LoanPayBima-Android select karo.
4) Repository menu > Show in Explorer.
5) IMPORTANT: repository ke andar hidden .git folder DELETE MAT KARNA.
6) Jo purani ZIP/demo files dikh rahi hain unko delete kar sakte ho.
7) Extracted project ke andar se:
   .github
   app
   build.gradle.kts
   gradle.properties
   settings.gradle.kts
   README.md
   in sabko COPY karo.
8) Repository folder Documents\GitHub\LoanPayBima-Android me PASTE karo.
9) GitHub Desktop par wapas jao.
10) Left side Changes dikhengi.
11) Summary me likho:
    Add LoanPayBima production foundation
12) Commit to main.
13) Push origin.
14) GitHub website kholo > LoanPayBima-Android > Actions.
15) Build LoanPayBima Android select karo > Run workflow.
16) Green tick aane ke baad run kholo.
17) Artifacts se LoanPayBima-debug-APK download karo.

AAB bhi workflow me banega, lekin Play Store ke liye release AAB ko upload key se SIGN karna zaroori hai.
