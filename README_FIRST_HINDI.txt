LOANPAYBIMA FINAL APP - SABSE AASAAN METHOD

1. Is ZIP par Right Click > Extract All.
2. Extracted folder open karo.
3. SETUP_TO_GITHUB_REPO.bat par DOUBLE CLICK karo.
4. Agar Windows warning aaye, More info > Run anyway sirf tab karein jab file isi ZIP se ho.
5. Script aapki GitHub Desktop repository automatic dhoondne ki koshish karegi.
6. Agar repository path mange:
   GitHub Desktop > Repository > Show in Explorer
   Explorer ke address bar ka poora path copy karke script me paste karo.
7. SUCCESS ke baad GitHub Desktop kholo.
8. Changes dikhengi.
9. Summary: Add LoanPayBima final Android app
10. Commit to main.
11. Push origin.
12. GitHub website > Actions > Build LoanPayBima Android.
13. Workflow complete hone par LoanPayBima-Install-APK artifact download karo.
